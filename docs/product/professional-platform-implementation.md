## Practical boundaries

- **Not deployed.** Source, migrations and local QA are delivered in this checkout. Existing pre-task modifications were preserved.
- Participant fees are a receipt-backed offline ledger. Charging cards and initiating refunds require a real payment-provider implementation and merchant configuration; the organization subscription remains separate.
- Video is a linked-evidence workflow. Licensed provider ingestion, hosted uploads/transcoding, automated event tagging and provider reconciliation require the chosen providers and contracts.
- Notice queueing reuses the durable communications infrastructure. No live emails were sent during this work; deliverability, callbacks and provider reconciliation need external acceptance evidence.
- Participant identity reuse pre-fills name and birth date for explicitly linked accounts. It does not copy prior consent, medical answers or private staff notes. Verification delivery and a populated real-family browser pilot still need provider/customer evidence.
- Evaluator readiness is explicitly self-reported. The coverage board sees server receipts, not unsent drafts on another device. Existing offline evaluation machinery was retained; newly added scouting/statistics forms require connectivity.
- Interactive scouting datasets are bounded at 10,000 rows and fail with an instruction to narrow the selection rather than calculate partial statistics. Scorecard history shows the latest 200 entries; recent evaluator activity shows the latest 1,000. Enterprise-scale performance needs deployment-specific load testing and further query specialization.
- Scenario approval uses organization managers. Customer-defined multi-step sign-off policies, SSO/SCIM/MFA enforcement, retention/legal-hold rules, hosted recovery drills, contracted support levels and a professional-team design-partner pilot remain buyer-specific implementation/acceptance work. Cross-provider video ingestion and editorial playlists remain provider-specific work; the current library groups linked evidence by athlete and saved filters.
